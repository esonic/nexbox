Core Features

不是功能堆砌，是范式重构

01 / AI WITH FULL CONTEXT

AI 拥有完整研发上下文

普通 AI 只知道你现在说的话。BoxNex 的 AI 知道任务背景、设计决策、历史 Review 意见、 代码规范规则，以及团队协作状态。 通过 MCP Server 暴露 20+ 工具，AI 不只是代码生成器，而是真正的研发伙伴。

02 / ASSET-CENTRIC

研发资产版本化管理

需求文档、设计文档、代码变更、测试用例，全部作为有版本、有状态、 可审阅的资产管理。行级 Review 评论，状态流转追踪，端到端可追溯。

requirement_doc design_doc code_change unit_test test_case
03 / WORKFLOW ENGINE

可视化工作流，灵活编排

DAG 可视化编辑器，支持 AI 节点、Human 审批节点、Map/Reduce 并行节点。 既可全自动流水线，也可关键节点人工介入。流程由你定义，不被工具绑架。

DAG Engine Parallel Exec Human-in-Loop
04 / LARK REMOTE

飞书远程控制 AI

离开电脑？用飞书机器人发条消息，指令自动注入到 BoxNex 当前 Session。 AI 执行完毕后，摘要和结果实时回复到飞书。随时随地，AI 不停工。

Lark Bot Async AI Smart Summary
05 / MULTI-AGENT

多 Agent 后端，No Vendor Lock-in

Claude Code、OpenAI Codex、Cursor CLI 无缝切换，统一事件协议。 不依赖单一供应商，模型更新、策略调整，一键适配。
